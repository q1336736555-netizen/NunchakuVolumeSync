# DAC专项

| 项目 | 平台 | 用途 |
| --- | --- | --- |
| [网易云音乐 USB 独占磁贴](usb-tile/) | Android | 在控制中心切换或查询网易云的 USB 独占状态。[下载 APK](usb-tile/apk/CloudUsbTile.apk) · [无线 ADB 调试](usb-tile/README.md#用无线-adb-接上-dac-调试) |

各项目的源码、资源和说明位于对应目录。在项目目录中运行该项目的构建命令。
